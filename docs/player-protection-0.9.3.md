# Yoru 0.9.3 — реклама, оригинал, каст и следующая серия

В Electron включена блокировка сетевой рекламы и рекламных элементов. Движок Ghostery Adblocker работает с поставляемыми офлайн-списками EasyList/EasyPrivacy, RU AdList и uBlock Origin. Фильтры не загружаются при запуске. В пакете находятся исходные списки, лицензии, точные ревизии и SHA-256: [происхождение и воспроизведение](../data/adblock/README.md).

Проверяются запросы всех плееров, включая вложенные iframe и прежние отдельные сессии. Новые окна запрещены. Рекламные IMA/VAST получают локальные совместимые ответы: отмена рекламы не должна оставлять плеер в ожидании отсутствующего SDK. Схема `yoru-adblock` обслуживает только зарегистрированные неизменяемые ресурсы движка; произвольных URL, файлов, Node.js или IPC в ней нет. HTTPS и изоляция страниц сохранены. Рекламу, вшитую в видеофайл, сетевой блокировщик убрать не может.

У AniLibria собственная русская озвучка. В каталоге выбор «Оригинал» теперь доступен как действие подбора других подтверждённых плееров той же серии. Поле «Перевод» предлагает «Найти оригинал с субтитрами». При отсутствии дорожки русское видео приостанавливается и появляется понятный результат с повтором; ролик не выдаётся за японскую дорожку. Быстрая смена обратно на русский отменяет намерение переключения, поздний ответ не меняет текущий выбор. Подтверждённые издания одного MAL-релиза объединяются, даже если дата фестивального показа и выпуска различается; при противоречащем ID или неоднозначных связях объединение запрещено. Доступны только опубликованные варианты; наличие оригинала для каждого спешла не выдумывается.

Каст подбирается по цепочке AniDB → MyAnimeList/Jikan → AniList. AniList запрашивается по точному MAL ID, дополнительно проверяется каноническое имя в индексе выбранного релиза. Год исходной карточки по-прежнему сверяется с индексом. Дата фестивального показа и дата выпуска в резервном API больше не обязаны совпадать, если ID и название уже подтверждены. Телесериал, спешл и продолжение по похожему имени не смешиваются. У трёх источников отдельные ID персонажей; роли, японские сэйю, фотографии, свои имена и заметки сохраняются.

Автопереход проверяется по настоящему окончанию видео у AniLibria и по подтверждённому событию выбранного iframe. Перевод и тайминг сохраняются. Отключённый автопереход не игнорируется, последняя серия не зацикливается. Для одноэпизодного релиза кнопка объясняет отсутствие продолжения; после конца сообщается, что у релиза одна серия. «Чёрный клевер (Спэшл)», AniLibria 5152, не является 170-серийным телевизионным релизом.

## Что проверяется

Сценарии используют собственный H.264/AAC 1080p-ролик и контролируемые ответы. Настоящий Electron обрабатывает рекламные URL через свой `webRequest`; заблокированные обращения не доходят даже до подставленного HTTPS-обработчика. После локальных IMA/VAST-замен проверяются настоящее декодирование видео/звука, субтитры, скрытый рекламный блок и отсутствие bridge/Node.js в странице. Это проверка блокировщика приложения, а не живой рекламы на конкретном сайте.

Дополнительно проверяются выбор оригинала после первоначального ответа только с русскими плеерами, поиск субтитров, отсутствие оригинала, повтор, быстрый возврат к русскому, резервный каст AniList/портреты/заметки после перезапуска и настоящее окончание серий.

Живые Yummyani/Kodik/AniDB/Jikan/AniList в облаке не проверены: их домены не разрешены действующей политикой сети revision 6. Воспроизведение конкретного тайтла и доступность из РФ/других стран не объявляются подтверждёнными. Итоговые результаты локальных/Windows-проверок и установщик публикуются в README и журнале проверок.
