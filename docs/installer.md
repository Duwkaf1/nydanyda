# Установка Yoru одним файлом

Для Windows 10/11 x64: **[скачать `Yoru-Setup-0.9.8-x64.exe`](https://github.com/Duwkaf1/nydanyda/releases/download/v0.9.8/Yoru-Setup-0.9.8-x64.exe)** — примерно 108 MiB, публичный файл Releases без входа в GitHub и без ZIP-обёртки. Это автономный установщик: интернет для установки, Node.js и права администратора не нужны. Для просмотра онлайн интернет нужен. После запуска открывается каталог AniLibria/AniLiberty: поиск, постеры, серии и воспроизведение загружаются автоматически. Вставлять ссылки не нужно. Поле «Где искать» переключает на расширенный каталог Yummyani; поддерживаемый плеер открывается внутри Yoru, с сериями, автопереходом и сохранением подтверждённого времени. Следующие страницы каталога загружаются при прокрутке.

1. Закрой прежнюю версию Yoru, особенно если запускал её из ZIP. Открой установщик и нажми **«Установить»**. При желании отключи ярлык на рабочем столе.
2. Нажми **«Готово»**, чтобы открыть Yoru. Позже приложение доступно в меню «Пуск».

По умолчанию приложение устанавливается только для текущего пользователя в `%LOCALAPPDATA%\Programs\Yoru`. Все компоненты Electron включены в один установочный EXE; после установки они лежат в папке приложения. Повторная установка обновляет файлы в той же папке. Если Yoru открыт, установщик попросит закрыть его: просмотр принудительно не завершается.

Для уменьшения размера используется сжатие LZMA. Из поставки убраны неиспользуемые языковые пакеты интерфейса Chromium: оставлены русский и английский для резервного варианта. Это не ограничивает язык звука или субтитров, кодеки и шрифты сохранены. Движок Electron остаётся внутри, поэтому установщик не может весить всего несколько мегабайт.

В **0.9.8** добавлены дозагрузка IMDb без ключа OMDb, проверенный запасной адрес постера, сохранение первой страницы на случай сбоя и резерв сериалов TVmaze. Проверка соединения теперь разбирает списки фильмов и сериалов и сохраняет коды ошибок. Internet Archive оформлен отдельно как архивные видео с неподтверждённым годом премьеры. [Проверки и ограничения](cinema-recovery-0.9.8.md).

В **0.9.7** добавлены годы, жанр, пороги IMDb/Rotten Tomatoes и сортировка фильмов и сериалов. По умолчанию выбраны последние три года. Для RT нужен личный ключ OMDb в «Настройки → Дополнительно»; IMDb доступен из Cinemeta при наличии оценки. [Проверка и ограничения](cinema-filters-0.9.7.md).

В 0.9.6 исправлен полный экран в основных и веб-плеерах, добавлены F11/Esc, пять источников кино по ссылке Кинопоиска и публичный выпуск EXE после проверок. Сезон и серия выбираются внутри зеркала. [Подробности](fullscreen-cinema-0.9.6.md).

В 0.9.5 исправлена проверка релиза «Квартал красных фонарей» с годом 2021 и зимним сезоном 2022 в индексе. [Результаты проверки популярных аниме](popular-cast-0.9.5.md). Отдельные появления по сериям для этих TV пока не подтверждены.

В 0.9.4 добавлены своя панель просмотра, управление реальным вложенным видео и восстановление при зависании в конце серии с учётом ручной паузы и настройки автоперехода. «Эта серия» в персонажах использует отдельные появления для поддержанного релиза; общий каст подписан отдельно. Подробнее — [отчёт 0.9.4](player-chrome-0.9.4.md).

По умолчанию работает офлайн-адблок Ghostery с EasyList/RU AdList/uBlock. Рекламные запросы и новые окна блокируются; IMA/VAST получают совместимые локальные ответы. Исходные списки, контрольные суммы и лицензии включены. Вшитая в сам видеофайл реклама не удаляется.

Выбор «Оригинал» в AniLibria запускает подбор другого плеера той же серии. В поле «Перевод» есть «Найти оригинал с субтитрами». При отсутствии вариантов доступен повтор; ошибочного продолжения на русском под видом оригинала нет. Каст получает независимый резерв AniList после AniDB/Jikan. Сохранены серии/автопереход/тайминг и загрузка каталога дальше 24 карточек. Одноэпизодный спешл не подменяется 170-серийным сериалом.

Сохранены фильмы/сериалы, поиск в видеосервисах через браузер, свободные фильмы Archive, оба встроенных движка, темы, полное удаление и резервные постеры. Наличие оригинала, нескольких переводов и 1080p у каждого релиза не гарантируется. Живые AniDB/Jikan/AniList/Yummyani пока не проверены из-за ограничений облачной сети; сетевой черновик требует публикации. [Возможности и ограничения](fullscreen-cinema-0.9.6.md).

Кнопка **Настройки → Дополнительно → Удалить приложение полностью** после системного подтверждения удаляет приложение и его профиль. По умолчанию в подтверждении выбрана «Отмена». При ошибке запуска приложение остаётся открытым. ZIP без установщика и запуск с отдельным профилем этим способом не удаляются. Деинсталлятор не переходит по ссылкам внутри профиля к посторонним файлам.

При обычном удалении через Windows библиотека, темы, прогресс и заметки остаются в прежнем профиле `%APPDATA%\kadr-anime`. Удаление через **Параметры Windows → Приложения → Yoru → Удалить** сохраняет профиль. Удаляются только поставленные файлы, ярлыки и запись приложения; посторонние файлы в папке не удаляются.

Иконка создана для Yoru с помощью генерации изображения: исходник в `assets/branding/yoru-icon-master.png`, многомасштабный ICO в `assets/yoru.ico` (16, 24, 32, 48, 64, 128, 256 px), PNG для окна Linux и веб-превью в `public/yoru-icon.png`. Иконка встроена в приложение, установщик и программу удаления; ярлыки используют иконку установленного EXE. Никаких чужих логотипов аниме в ней нет.

Сборка не подписана сертификатом издателя, поэтому Windows может показать предупреждение о неизвестном издателе. Подпись и проверка репутации SmartScreen не заменяются собственной иконкой.

## Сборка из исходников

Нужны Node.js 24 и бесплатный **NSIS 3.11** (zlib/libpng licence; не включается в установленное приложение). На Windows: `choco install nsis --version=3.11 -y`; либо установи NSIS с официального сайта. На Linux нужен пакет `nsis`. Если компилятор не в PATH, укажи `MAKENSIS` — полный путь к `makensis` / `makensis.exe`.

```sh
npm ci
npm run installer:win
```

Результат — `artifacts/Yoru-Setup-0.9.8-x64.exe` и соседний файл SHA-256. Уже упакованное приложение можно превратить в установщик командой `node scripts/build-installer.js`. Сохраняется и прежняя ZIP-сборка для запуска без установки.

После Windows-проверок GitHub Actions публикует установщик, SHA-256 и переносимый ZIP в [Releases](https://github.com/Duwkaf1/nydanyda/releases/tag/v0.9.8). Для загрузки публичных файлов аккаунт не нужен. Самому установщику дополнительные файлы не нужны; для переносимой версии распакуй всю папку из ZIP.

## Проверка

Windows CI проверяет видимые русские кнопки установки, установку без запроса повышения прав, ярлыки и регистрацию версии; повторную установку; запуск **реального установленного `Yoru.exe`** с проверками тем, видео, звука и субтитров; защиту открытого приложения от перезаписи; удаление с сохранением профиля и посторонних файлов; установку в путь с пробелами и кириллицей. Проверка предназначена для отдельного CI-окружения, а не личного компьютера.

[Проверка 0.9.8 на Windows — успешно](https://github.com/Duwkaf1/nydanyda/actions/runs/41639932463), исходники `d8c9634`. Установка, native-проверка приложения, повторная установка, обычное удаление и полное удаление из настроек прошли. Отмена сохранила приложение; подтверждение удалило профиль, ярлыки и регистрацию. Посторонние файлы и цель junction внутри профиля сохранились. Оба артефакта загружены, проверенные файлы опубликованы в Releases.

Установочный EXE: **113 518 025 байт**; SHA-256 `59a64752e00f95ed15cdcf852d357e47e32730528d4f1daa19f9eeff6c99d2f0`. Контрольная сумма самого EXE также лежит рядом с ним в Releases.

Результат следующих прогонов смотри в [Windows Actions](https://github.com/Duwkaf1/nydanyda/actions/workflows/windows.yml). Это автоматическая проверка на виртуальной Windows, не проверка SmartScreen на каждом компьютере.
