# Установка Yoru одним файлом

Для Windows 10/11 x64: **[скачать `Yoru-Setup-0.9.2-x64.exe`](https://github.com/Duwkaf1/kinoteatr-xivivide/actions/runs/41280569130/artifacts/13072634143)** — примерно 104 MiB. Это автономный установщик: интернет для установки, Node.js и права администратора не нужны. Для просмотра онлайн интернет нужен. После запуска открывается каталог AniLibria/AniLiberty: поиск, постеры, серии и воспроизведение загружаются автоматически. Вставлять ссылки не нужно. Поле «Где искать» переключает на расширенный каталог Yummyani; поддерживаемый плеер открывается внутри Yoru, с сериями, автопереходом и сохранением подтверждённого времени. Следующие страницы каталога загружаются при прокрутке.

1. Закрой прежнюю версию Yoru, особенно если запускал её из ZIP. Открой установщик и нажми **«Установить»**. При желании отключи ярлык на рабочем столе.
2. Нажми **«Готово»**, чтобы открыть Yoru. Позже приложение доступно в меню «Пуск».

По умолчанию приложение устанавливается только для текущего пользователя в `%LOCALAPPDATA%\Programs\Yoru`. Все компоненты Electron включены в один установочный EXE; после установки они лежат в папке приложения. Повторная установка обновляет файлы в той же папке. Если Yoru открыт, установщик попросит закрыть его: просмотр принудительно не завершается.

Для уменьшения размера используется сжатие LZMA. Из поставки убраны неиспользуемые языковые пакеты интерфейса Chromium: оставлены русский и английский для резервного варианта. Это не ограничивает язык звука или субтитров, кодеки и шрифты сохранены. Движок Electron остаётся внутри, поэтому установщик не может весить всего несколько мегабайт.

В 0.9.2 просмотр Yummyani переведён в область видео Yoru. Добавлены подгрузка каталога дальше 24 карточек, автоматическая следующая серия с тем же переводом, обнаружение зависания и резерв после 30 секунд без продвижения. Повтор обновляет временную ссылку. Очередь AniDB и резерв MyAnimeList/Jikan автоматически загружают проверенный каст при отказе или изменении разметки AniDB. Ручные XML и ссылки для этого потока не нужны.

Сохранены фильмы/сериалы, поиск в видеосервисах через браузер, свободные фильмы Archive, оба встроенных движка, темы, полное удаление и резервные постеры. Наличие оригинала, нескольких переводов и 1080p у каждого релиза не гарантируется. Живые AniDB/Jikan/Yummyani пока не проверены из-за ограничений облачной сети; сетевой черновик требует публикации. [Возможности и ограничения](managed-anime-0.9.2.md).

Кнопка **Настройки → Дополнительно → Удалить приложение полностью** после системного подтверждения удаляет приложение и его профиль. По умолчанию в подтверждении выбрана «Отмена». При ошибке запуска приложение остаётся открытым. ZIP без установщика и запуск с отдельным профилем этим способом не удаляются. Деинсталлятор не переходит по ссылкам внутри профиля к посторонним файлам.

При обычном удалении через Windows библиотека, темы, прогресс и заметки остаются в прежнем профиле `%APPDATA%\kadr-anime`. Удаление через **Параметры Windows → Приложения → Yoru → Удалить** сохраняет профиль. Удаляются только поставленные файлы, ярлыки и запись приложения; посторонние файлы в папке не удаляются.

Иконка создана для Yoru с помощью генерации изображения: исходник в `assets/branding/yoru-icon-master.png`, многомасштабный ICO в `assets/yoru.ico` (16, 24, 32, 48, 64, 128, 256 px), PNG для окна Linux и веб-превью в `public/yoru-icon.png`. Иконка встроена в приложение, установщик и программу удаления; ярлыки используют иконку установленного EXE. Никаких чужих логотипов аниме в ней нет.

Сборка не подписана сертификатом издателя, поэтому Windows может показать предупреждение о неизвестном издателе. Подпись и проверка репутации SmartScreen не заменяются собственной иконкой.

## Сборка из исходников

Нужны Node.js 24 и бесплатный **NSIS 3.11** (zlib/libpng licence; не включается в установленное приложение). На Windows: `choco install nsis --version=3.11 -y`; либо установи NSIS с официального сайта. На Linux нужен пакет `nsis`. Если компилятор не в PATH, укажи `MAKENSIS` — полный путь к `makensis` / `makensis.exe`.

```sh
npm ci
npm run installer:win
```

Результат — `artifacts/Yoru-Setup-0.9.2-x64.exe` и соседний файл SHA-256. Уже упакованное приложение можно превратить в установщик командой `node scripts/build-installer.js`. Сохраняется и прежняя ZIP-сборка для запуска без установки.

GitHub Actions собирает отдельный артефакт **Yoru-installer-x64** с установщиком и контрольной суммой. GitHub скачивает артефакты в ZIP-обёртке: извлеки из неё установочный EXE один раз. Самому установщику дополнительные файлы не нужны. Артефакты имеют ограниченный срок хранения.

## Проверка

Windows CI проверяет видимые русские кнопки установки, установку без запроса повышения прав, ярлыки и регистрацию версии; повторную установку; запуск **реального установленного `Yoru.exe`** с проверками тем, видео, звука и субтитров; защиту открытого приложения от перезаписи; удаление с сохранением профиля и посторонних файлов; установку в путь с пробелами и кириллицей. Проверка предназначена для отдельного CI-окружения, а не личного компьютера.

[Проверка 0.9.2 на Windows — успешно](https://github.com/Duwkaf1/kinoteatr-xivivide/actions/runs/41280569130), исходники `42d3c67`. Установка, native-проверка приложения, повторная установка, обычное удаление и полное удаление из настроек прошли. Отмена сохранила приложение; подтверждение удалило профиль, ярлыки и регистрацию. Посторонние файлы и цель junction внутри профиля сохранились. Оба артефакта загружены.

Установочный EXE: **109 224 924 байт**; SHA-256 `bf80d152da2b8011fae8b0af7a1b74ebb8eaad10bd6d5e762bd061f3241ffeb0`. Контрольная сумма самого EXE также лежит рядом с ним в артефакте.

Результат следующих прогонов смотри в [Windows Actions](https://github.com/Duwkaf1/kinoteatr-xivivide/actions/workflows/windows.yml). Это автоматическая проверка на виртуальной Windows, не проверка SmartScreen на каждом компьютере.
