# Yoru 0.9.1 — автоматические озвучки, переводы и персонажи

В 0.9.0 встроенный каталог AniLibria загружал только её русскую дорожку. Другие дорожки и субтитры требовали ручного добавления, а состав AniDB — ручной привязки. В 0.9.1 добавлен автоматический подбор; основной поток начинает играть сразу при обычном выборе AniLibria. При продолжении выбранной онлайн-дорожки он остаётся на паузе до её загрузки, чтобы вместо оригинала не включилась другая озвучка.

## Озвучки и переводы

Под видео появился быстрый выбор **«Плеер и озвучка»**, когда у серии есть несколько вариантов. Приложение запрашивает список видео Yummyani для точно сопоставленного релиза. Используются настоящий `data.dubbing` и название плеера из ответа; «Студия А/Б» не создаются. Сопоставление требует точного AniLibria alias или проверенного MAL ID и совпадающего года. Несколько подходящих карточек не объединяются наугад. Для API предусмотрены legacy-host и текущий `api.yani.tv`, тайм-ауты, отмена старых запросов и ограниченный кэш.

В **«Озвучка → Оригинал»** появляются опубликованные оригинальные дорожки. В **«Перевод»** — предоставленные сайтом варианты субтитров с именами команд. При выборе оригинала приоритет имеют варианты с субтитрами. Явно обозначенные английские/украинские варианты не выдаются за русские.

Онлайн-плеер открывается **на странице просмотра Yoru** в изолированном iframe. Разрешены только известные домены плееров из API, скрипты страницы не извлекаются, защищённые потоки не расшифровываются. У iframe нет `window.kadr`, Node.js, права открыть всплывающее окно, скачать файл или заменить страницу приложения. Источник сообщений и origin проверяются.

**Разрешение, выключение встроенных в видео субтитров и оформление онлайн-перевода управляются самим плеером.** В этом случае поле качества Yoru честно показывает «В плеере». Максимальное разрешение в подписи варианта появляется только из метаданных провайдера. Для оформленных субтитров исправлено очищение неподвижного кадра при повторном resize без изменения геометрии; настоящий размер и позиция продолжают обновляться. В основном/альтернативном встроенных движках сохранены прямые MP4/WebM/HLS, оригинал, текстовые и оформленные субтитры.

Не каждое аниме имеет несколько озвучек, переводов или 1080p. Приложение не создаёт недостающий контент. Недоступный API не останавливает уже играющую AniLibria; есть повтор подбора. Неподдерживаемый iframe-host не превращается в произвольный привилегированный URL.

## История

Для Kodik/совместимых доменов добавлен приём подтверждённого времени по документированному протоколу сообщений и восстановление позиции. Сохраняется выбранная команда и плеер; временные адреса заново загружаются при открытии. [Описание протокола](https://github.com/track-anime/track-anime.github.io/blob/main/docs/kodik-api/player-api.md).

Постороннее окно не может изменить историю. Запоздавший ответ другого аниме игнорируется. Если серия переключена внутри чужого плеера, время не записывается под прежнюю серию. Выбирай серии в Yoru для правильной истории. Если конкретный iframe не передаёт время, хранится только последний подтверждённый тайминг: синхронизация не выдумывается.

Прежнее 30-секундное восстановление прямых потоков сохранено. Универсальное автоматическое переключение всех сторонних iframe с гарантией той же дорожки, монтажа и качества не заявляется.

## Персонажи

Для аниме каталога автоматически определяется AniDB ID. В поставку включён индекс **13 656 точных соответствий MAL ↔ AniDB**, канонические названия, синонимы и год. Сверяются ID, название и год; приблизительного поиска по похожему названию нет.

Список и фотографии загружаются с публичной страницы выбранного аниме AniDB без пользовательского XML и зарегистрированного HTTP-клиента. Проверяется canonical URL страницы. Главные персонажи показываются перед второстепенными. Свои имена, фотографии и заметки сохранены; кэш ограничен, сайт не опрашивается на каждой секунде видео. При кратком ограничении частоты предусмотрена одна отложенная попытка, при отказе — сохранённый состав и кнопка повтора. Ручной API/XML остаётся дополнительной возможностью для собственной библиотеки.

Состав относится к релизу/сезону. Полный подтверждённый список появления каждого персонажа в каждой серии AniDB таким способом не предоставляет; ручные отметки серий не выдаются за автоматические.

Индекс основан на [anime-offline-database 2026-27](https://github.com/manami-project/anime-offline-database/releases/tag/2026-27), **ODbL-1.0 / DbCL-1.0**. Производная база и лицензия открыты в `data/`; контрольные суммы — `anime-crosswalk.provenance.json`, воспроизведение — `scripts/generate-crosswalk.js`. Лицензия входит в Windows-поставку. Данные персонажей и картинки принадлежат их правообладателям.

Добавлена отдельная проверяемая коррекция для alias `black-clover-special`, 2016 года и одной серии: MAL **33950**, AniDB **12351**, *Black Clover: Jump Festa 2016 Special*. 1080p не включается подменой адреса или растягиванием 720p. Другое качество доступно только там, где его действительно предоставляет выбранный плеер.

## Что подтверждено, а что ещё нет

Unit-проверки и браузерные/нативные сценарии используют контролируемые ответы API, архивный состав *Arcade Gamer Fubuki* и собственный короткий H.264/AAC-файл. Они проверяют реальное декодирование 1080p в изолированном iframe, оба встроенных движка, автоматический выбор вариантов, роли/фотографии, личные заметки, ошибки, смену контекста и историю. Они не являются живым воспроизведением аниме у стороннего сайта.

В облачной среде AniDB, Yummyani и AnimeJoy отклоняются на CONNECT с **403**. Действующая политика revision 6 не включает эти домены. Нужные домены, включая текущий API и поддерживаемые iframe, сохранены в сетевой черновик; его должен сохранить и опубликовать пользователь в настройках среды. Пока это не сделано, совместимость с текущими живыми ответами/видеоплеерами и работа из РФ не подтверждены. Ограничение среды не выдаётся за отказ сервисов на пользовательском ПК.

Точные итоговые числа проверок, Windows CI и ссылка на установщик публикуются в README.md и docs/validation.md репозитория. Эта версия не объявляется доказательством, что каждый релиз во всех странах имеет оригинал, несколько русских переводов и 1080p.
