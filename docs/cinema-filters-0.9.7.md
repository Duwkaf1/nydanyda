# Yoru 0.9.7 — новые фильмы, сериалы и рейтинги

По умолчанию разделы «Фильмы» и «Сериалы» показывают названия за последние три календарных года (в 2026 году: 2024–2026). Доступны «С 2020 года», «Все годы», свой диапазон, жанр, минимальный IMDb и Rotten Tomatoes. Фильтры годов, оценок и порядок сохраняются отдельно для фильмов и сериалов. Поиск названия учитывает выбранные фильтры; для старого фильма выберите «Все годы».

Популярность соответствует порядку общего каталога Cinemeta. «Сначала новые», IMDb и Rotten Tomatoes сортируют уже загруженные карточки; это не обещание глобального рейтинга всех фильмов. «Показать ещё» продолжает от фактически прочитанной позиции: неподходящие годы не пропускают подходящие карточки на стыках страниц. За запрос просматривается не больше 300 исходных записей. Если совпадений нет, но источник продолжается, можно загрузить следующую часть.

При недоступности Cinemeta приложение сохраняет выбранный источник и фильтры и предлагает повторить загрузку. Оно больше не подменяет современные фильмы архивной классикой. Internet Archive выбирается отдельно как «Классика»; его свободные фильмы могут отсутствовать в современном диапазоне. TVmaze — отдельный резервный каталог сериалов, а его собственная оценка подписана TVmaze.

## IMDb и Rotten Tomatoes

IMDb из Cinemeta показывается по шкале 10. Для дополнительных оценок доступна интеграция OMDb по точному IMDb ID и типу произведения. Оценка критиков Rotten Tomatoes показывается в процентах; отсутствие оценки обозначается прочерком, а реальный 0% сохраняется.

Ключ OMDb вводится в **Настройки → Дополнительно → IMDb и Rotten Tomatoes**. Получение личного ключа: https://www.omdbapi.com/apikey.aspx. OMDb определяет доступность полей, актуальность, тариф и лимит запросов. Общий ключ в приложение не встроен. Без личного ключа RT недоступен; фильтр по RT сообщает о необходимости подключения. При отсутствии оценки карточка не проходит порог соответствующего рейтинга.

Ключ передаётся только фиксированному HTTPS API OMDb, хранится через Electron safeStorage с шифрованием ОС и не возвращается renderer через статус. В отсутствие защищённого хранилища остаётся только до закрытия приложения. Ключ не входит в библиотеку и её экспорт; его можно удалить в настройках. Одновременно выполняется до трёх запросов оценок, кэш ограничен, время запроса ограничено. Ответы с другим IMDb ID или типом отвергаются.

## Проверка

134 unit-теста прошли; новые проверки охватывают диапазоны, неизвестные оценки, шкалы IMDb/RT, 0%, точную идентичность OMDb, ограничение сканирования, продолжение без потерь и шифрованное хранение ключа. **139 браузерных сценариев** полным прогоном прошли за 7,1 минуты. После прогона код приложения не менялся. Пересозданы 57 контролируемых снимков, шесть исторических живых снимков сохранены отдельно. Новые browser-сценарии проверяют реальные начальные настройки, фильтр IMDb, свой диапазон, сохранение отдельно для фильмов и сериалов, RT, удаление ключа и узкое окно. Старые сценарии классики явно выбирают «Все годы».

Native-проверка настоящего Linux Electron прошла, включая изолированный IPC, настройку и удаление ключа и отдельные IMDb/RT по контролируемым ответам API. Сохраняются проверки полноэкранного режима, паузы, времени просмотра, зеркал, двух движков, установки, обновления и удаления. Контролируемые ответы не являются подтверждением живых оценок или доступности видео.

Живые Cinemeta/TVmaze/OMDb в этой облачной сессии не проверены: конфигурация сети ограничена, расширенный сетевой черновик сохранён, но не опубликован; личного ключа OMDb нет. В Windows доступ определяется сетью пользователя и его ключом. Источники видео и их ограничения описаны в [проверке 0.9.6](fullscreen-cinema-0.9.6.md).

[Windows CI](https://github.com/Duwkaf1/nydanyda/actions/runs/41621658949) успешен: 134 unit-теста, production build, настоящий Electron и фактически установленный EXE, установка, обновление, отмена и удаление. Исходники сборки `1924b0d6946151f33b7efa82fd944dccac748596`; код приложения соответствует `8f34e4a` (следующий коммит добавляет только диагностику CI).

Первый Windows-прогон 41620978454 остановился на desktop smoke с общим exit code 1; архив логов был закрыт текущей облачной сетью, точная причина не установлена. В workflow добавлена постоянная аннотация с последними строками ошибки. Повторный прогон прошёл без изменения кода приложения; отсутствие воспроизведения не объявляется исправлением неизвестной причины.
