# Yoru 0.9.8 — загрузка каталогов, постеры и оценки

В 0.9.7 пользователь получил ошибку общего каталога при успешной проверке его manifest.json, а в Internet Archive — видеопревью, названия архивных загрузок и 2026 как год старых фильмов. Unit/browser/native-проверки с контролируемыми ответами не установили причину сбоя живого запроса на компьютере пользователя. Поэтому доступность внешних каталогов и видео здесь не объявляется подтверждённой.

## Изменения

- Проверка соединения запрашивает и разбирает **списки Cinemeta отдельно для фильмов и сериалов**. Проверка обходит кратковременный кэш и выполняет новый запрос. HTTP 200 с HTML вместо JSON больше не считается рабочим каталогом. TVmaze подписан отдельно. Для видеосайтов проверяется только доступность страницы.
- Ошибки сохраняют адрес сервиса и код: `HTTP 403/503`, `DNS`, `NETWORK`, `TIMEOUT`, `REDIRECT`, `INVALID_JSON_OR_SIZE`. Браузерный gateway передаёт исходную диагностическую ошибку даже при ответе 502. Значения API-ключей и полные URL запросов не включаются в эти сообщения.
- Канонические перенаправления разрешены в пределах того же HTTPS origin, максимум три перехода; переход на другой origin отклоняется. Произвольные адреса из renderer не принимаются.
- Сбой следующей страницы сохраняет уже полученные современные карточки и позицию продолжения. Последняя успешная первая страница хранится локально до семи дней, отдельно для точных условий поиска; до шести записей с ограничением общего объёма. При сетевом сбое показаны дата и предупреждение об актуальности. Если ни одной успешной загрузки ещё не было, кэш пуст: он не заменяется выдуманным каталогом.
- При сбое Cinemeta сериалы могут перейти на независимые **расписания TVmaze**: эфир США и веб-премьеры за последние три дня, с удалением дублей. Источник и охват подписаны; годы/жанр/пороги сохраняются. Это не глобальная сортировка по популярности. Фильмы не подменяются архивными видео.
- IMDb дозагружается из точной карточки Cinemeta **без ключа OMDb**, даже когда краткий список не содержит оценки. Из этой же карточки берётся постер и проверенный запасной адрес изображения. Несовпадающий IMDb ID отвергается. Неудавшаяся загрузка оценки завершается сообщением о недоступности, а не вечным индикатором.
- **Rotten Tomatoes по-прежнему требует личного ключа OMDb**. Интеграция не создаёт оценки там, где сервис их не предоставляет. Ключ хранится с шифрованием ОС, при отсутствии защищённого хранилища — только в памяти.
- Internet Archive переименован в «Архивные видео»: его автоматическая миниатюра подписана «Архивное превью» и не растягивается под постер. Год архивной записи не выдается за премьеру. До точного сопоставления IMDb оценки не обещаются; годы, пороги оценок и сортировка по ним для архивных записей отключены. Привязка только по похожему названию не создаётся.

## Проверка

143 unit-теста, production build и 43 целевых browser-сценария (кино, каталог аниме, автоматические источники) проверяют изменения. Настоящий Linux Electron прошёл проверки воспроизведения/звука/субтитров, обоих движков, полноэкранного режима и F11/Esc, изоляции удалённых окон и настройки ключа. Новые сценарии отдельно воспроизводят HTML вместо JSON, безопасный/чужой redirect, HTTP 403/503, сбой второй страницы, точный IMDb без ключа, исходный постер и запасной адрес, кэш после перезапуска, недопустимость кэша для другого фильтра и неподтверждённый год архивной записи. Ответы провайдеров в этих сценариях контролируемые.

В облачной среде соединение с рабочими файлами восстановилось, изменения внесены и проверены. Активная политика сети остаётся ревизии 6 и не разрешает Cinemeta/TVmaze/OMDb; сохранённый расширенный сетевой черновик не опубликован. Это ограничение облачной проверки не устанавливает причину ошибки на компьютере пользователя. Разрешённая страница популярного кино Кинопоиска ответила перенаправлением на SSO; она не принята за независимый каталог. Обход сетевых ограничений не выполнялся.

В native smoke добавлено ожидание подтверждённой паузы в кнопке перед нажатием воспроизведения: факт паузы удалённого видео и обновление интерфейса приходят асинхронно. При сбое автоперехода тест выводит состояние видео, подпись кнопки и название серии для диагностики. Это изменение тестового сценария, не отключение проверки фактического окончания ролика.
