# Yoru 0.9.4 — управление просмотром и персонажи серии

У плеера своя панель Yoru: SVG-кнопки, время, перемотка, громкость, отключение звука и полный экран. Качество и оформление перевода стороннего плеера открываются кнопкой с шестерёнкой; возврат к панели Yoru сохраняет выбранную серию.

Настольная версия наблюдает реальное HTML5-видео выбранного опубликованного iframe, включая вложенный iframe другого домена. Передаются только состояние и ограниченные команды play/pause/seek/volume/mute. URL потока, скрипты, ключи и токены не извлекаются. Удалённая страница не получает Node, preload или IPC. Главный процесс проверяет отправителя, разрешённый адрес и текущую привязку; старый плеер не может управлять новой серией. Kodik postMessage остаётся резервом. Плеер без доступного HTML5-видео и без поддерживаемого API может остаться неуправляемым.

Если видео застряло не дальше 1,25 секунды от конца, после 8 секунд без движения серия завершается. Нужны подтверждённые время, длительность от 30 секунд и прежнее намерение воспроизводить; ручная пауза блокирует этот путь. Настройка автоперехода учитывается. Обычное окончание видео переключает серию сразу. Зависание в середине использует установленный таймаут восстановления и сохраняет подтверждённую позицию, тип дорожки, перевод и качество. Полный отказ всех серверов не устраняется приложением.

Выбор оригинала сначала подбирает соответствующий опубликованный источник. При отсутствии японского варианта русский источник приостанавливается, а поле озвучки возвращается к фактическому варианту. Текущий API Yummyani проверяется раньше старого; поиск продолжает проверять второе название и подтверждённые издания того же MAL, если первый результат содержит только русский дубляж. Разрешены опубликованные Sibnet и обёртки Yummyani наряду с Kodik. Номер из одного сервиса не превращается в ссылку другого сервиса.

У персонажей появился быстрый выбор «Весь релиз / Эта серия». Для TV «Чёрный клевер» (MAL 34572, AniDB 12665, серии 1–170) подключён отдельный адаптер раздела Characters in Order of Appearance на странице Episode N в Black Clover Wiki. Он сопоставляет имена/алиасы с кастом релиза, учитывает перестановку имени и фамилии, исключает соседние разделы и чужие ссылки. Неполное совпадение имён может дать неполный список. Ручные отметки сохраняются отдельно и явно подписаны. Для одноэпизодного релиза общий каст подписывается как каст одного эпизода. Для остальных релизов без подтверждённого источника появлений предлагается явно открыть весь релиз; сезонный список не выдаётся за список серии.

## Границы живой проверки

Старая пользовательская ссылка Trout `/283290` вернула HTTP 503, Brogiro `/series/283290/` — HTTP 404. Подставлять этот номер каждому аниме нельзя. Для каждого релиза/эпизода используются реальные iframe URL из ответа каталога, с точной проверкой соответствия релиза; TV и спэшл не смешиваются.

Живые Yummyani/api.yani.tv/Kodik/AniDB/Jikan/AniList/Black Clover Wiki в этой среде пока не проверены: действующая сеть revision 6 их не разрешает. Сохранённый сетевой черновик требует публикации пользователем. Поэтому здесь нет обещания, что японская дорожка/перевод или появления доступны для каждого реального эпизода. Тесты используют контролируемые API/HTML, собственный H.264/AAC-ролик и настоящий Electron; они проверяют код и декодирование, а не наличие японского аниме у поставщика. Fandom-разметка и фактический список появлений остаются без живого подтверждения.

## Проверки

Итоги полного прогона и Windows-сборки публикуются в [validation.md](validation.md). В отдельной проверке настоящего Electron воспроизводится H.264/AAC 1080p во вложенном iframe другого домена без API провайдера: собственная панель управляет play/pause/seek/mute, а реальный ended открывает следующую серию. Проверены sandbox/context isolation и отсутствие Node/IPC у удалённого видео.
