# Yoru — скриншоты интерфейса

Галерея содержит **72 PNG**. Для 0.9.9 обновлены 15 снимков кино, Lordfilm и настроек без ключей; 50 прочих воспроизводимых снимков сохранены с 0.9.7, шесть исторических живых — с 0.8.2. Контролируемые ответы не подтверждают живую доступность внешних сервисов.

Версия 0.9.6 проверяет полный экран, F11/Esc и сохранение состояния, пять новых источников кино по ID Кинопоиска и публичную загрузку установщика. Снимки просмотра используют собственное видео и контролируемые API. [Проверки и ограничения](../fullscreen-cinema-0.9.6.md).

## Повторить снимки

После успешного полного `npm run test:e2e` выполни `node scripts/update-gallery.js`. Скрипт сначала проверяет наличие 51 воспроизводимого снимка и затем копирует их в галерею. Шесть `catalog-live-*.png` он не заменяет: они получены отдельным живым прогоном и требуют повторной проверки настоящего сервиса. Для персонажей используется подготовленный состав с фотографиями (`character-photos.png`), а не диагностический экран ручных отметок серий.
