# Просмотр Yummyani внутри Yoru — 0.9.2

Исправлена передача просмотра из расширенного каталога в отдельное окно сайта. Карточка теперь получает опубликованные серии через API Yummyani и открывает поддерживаемый плеер в области видео Yoru. Список серий, кнопка «Далее», история, избранное и восстановление выбранной озвучки относятся к карточке Yummyani, а не к совпавшему числовому ID AniLibria.

## Каталог

24 — размер одной страницы API. При приближении к концу списка автоматически загружается следующая страница. Счётчик сообщает, сколько показано, и не выдаёт неизвестный общий размер каталога за 24. Кнопка дополнительной загрузки сохранена для клавиатуры. Повторяющаяся страница без новых карточек останавливает подгрузку; изменение запроса/фильтров отменяет старую загрузку. Кроме старого API поддерживается фиксированный текущий адрес `api.yani.tv` с сохранением всех условий поиска.

## Серии, оригинал и восстановление

Для просмотра из Yummyani используются опубликованные iframe Kodik/Aniqit: их интерфейс позволяет приложению получать время, паузу, воспроизведение и окончание серии. Окончание запускает следующую доступную серию с той же озвучкой и переводом. История хранит только подтверждённую позицию выбранного iframe; сообщения главной страницы и прежних кадров игнорируются.

При отсутствии продвижения во время воспроизведения в течение заданного ожидания (по умолчанию 30 секунд) выбирается другой подтверждённый вариант: сначала та же озвучка, затем разрешённый настройками приоритет. Тип аудио, наличие субтитров и подтверждённый верхний предел качества сохраняются. Каждый отказавший вариант исключается из текущей цепочки; исчерпание вариантов предлагает повтор с обновлением временных ссылок. Обычная пауза не считается зависанием. Это восстановление соединения, а не гарантия непрерывного интернета.

Оригинал и переводы определяются по опубликованной подписи и явным полям типа перевода. Поддерживаются подписи `dubbing`, `translation`, признак субтитров и объект перевода. Обзор под видео отдельно показывает число озвучек, вариантов оригинала и переводов. Шесть русских плееров не означают шесть вариантов оригинального аудио. Если у конкретного релиза оригинал не опубликован, он не подставляется из другого сезона/спешла.

Разрешение и оформление субтитров iframe выбираются в самом плеере. Yoru не выдаёт верхний предел из API за фактическое текущее разрешение кадра и не подменяет отсутствующее 1080p масштабированием. Для прямых источников остаются обе встроенные системы и точный выбор разрешения.

Страницы сайта и iframe без подтверждённого протокола управления не предлагаются вместо управляемого просмотра каталога. Если подходящего плеера нет, карточка сообщает об этом и остаётся в Yoru. Группировка видео по серии выполняется одним проходом, без повторного перебора всего списка для каждого эпизода. Временные ссылки плееров не сохраняются как ручные источники; при повторном открытии обновляются.

## Персонажи

Быстрая смена тайтлов ставит запросы AniDB в очередь с интервалом не менее пяти секунд. Вместо мгновенного отказа «AniDB просит подождать» запрос ждёт своего места; отменённые запросы пропускаются. Ответы ограничены по размеру, времени и объёму кэша.

При сетевом отказе, ограничении или изменении разметки AniDB используется MyAnimeList через публичный API Jikan. Перед запросом персонажей дополнительно сверяются MAL ID, название и год исходного релиза. Каст другого сезона не подставляется. Главные и второстепенные роли, японские сэйю и доступные портреты загружаются автоматически. Резервный источник обозначается в интерфейсе; ID персонажей разных каталогов не пересекаются, личные заметки и имена остаются привязанными к своему источнику.

Скриншот пользователя показывает библиотеки для HTTP/UDP API AniDB. Зарегистрированный HTTP-клиент остаётся доступен в дополнительных настройках; чужой client ID не используется. Автоматический поток не требует от пользователя XML или регистрации клиента. Поэпизодное появление персонажей не выдумывается.

## Граница проверки

Автоматические сценарии используют контролируемые ответы внешних API и собственный H.264/AAC-ролик с настоящим декодированием видео/звука. Они проверяют поведение приложения, а не наличие оригинала, субтитров и 1080p для каждого аниме.

Действующая облачная политика сети revision 6 не разрешает Yummyani, Kodik, AniDB и Jikan. Нужные домены уже находятся в сохранённом черновике конфигурации (revision 22); публикация черновика не выполнена. Запросы к отклонённым доменам не повторялись через другие каналы. Живые видео, текущие ответы этих API и работа из РФ/других стран в этой версии остаются непроверенными. Это ограничение среды проверки, а не заключение о доступности сервисов на пользовательском компьютере.

Итоговые результаты тестов, Windows-сборка и установщик приведены в README и журнале проверок.
